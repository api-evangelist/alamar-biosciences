# Alamar Biosciences

> Alamar Biosciences is a privately held precision-proteomics company in Fremont, California.
> Its NULISA (NUcleic acid Linked Immuno-Sandwich Assay) chemistry and Attobody reagents, run
> on the ARGO and ARGO HT automated immunoassay systems, measure hundreds of proteins per
> sample at attomolar sensitivity for biomarker discovery and translational research.
>
> Alamar publishes NO public web API. There is no developer portal, no OpenAPI, no GraphQL
> endpoint, no MCP server and no A2A agent card. Its public developer surface is a single
> first-party open-source R package for analyzing the output of its own instruments.
>
> Generated by API Evangelist from public sources on 2026-08-06. This is a third-party
> profile; API Evangelist does not operate Alamar Biosciences software.

## Software

- [NULISAseqR](https://github.com/Alamar-Biosciences/NULISAseqR): First-party R package (GPL-3,
  v1.5.1) for NULISAseq proteomic data — XML import, intra- and inter-plate normalization
  against internal controls, quality control, limit of detection and detectability,
  differential abundance modeling, heatmap/PCA/volcano visualization, and automated HTML QC
  reports. Not on CRAN; install with
  `devtools::install_github('Alamar-Biosciences/NULISAseqR')`.
- [NULISAseqR documentation](https://nulisaseqr.alamarbio.com/): pkgdown site.
- [Function reference](https://nulisaseqr.alamarbio.com/reference/index.html)
- [User guide](https://nulisaseqr.alamarbio.com/user-guide/)
- [Changelog](https://nulisaseqr.alamarbio.com/news/): dated release notes, 1.4.0 through 1.5.1.
- [Issues](https://github.com/Alamar-Biosciences/NULISAseqR/issues)
